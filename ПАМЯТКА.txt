ПАМЯТКА: Great Turtle
=====================

1. ЗАПУСК И ФАЙЛЫ
-----------------
Папка программы: D:\GreatTurtle  (app.pyw, core.py, engine.py - всегда заменяйте все три вместе).
Папка загрузок:  D:\hitomi_downloader_GUI
Запуск: двойной щелчок по app.pyw.
Журнал: Инструменты -> Журнал (там ошибки yt-dlp, строки [формат], [дорожки]).


2. ОБНОВЛЕНИЕ yt-dlp (первое, что надо делать при ошибках YouTube)
------------------------------------------------------------------
Инструменты -> Обновить yt-dlp   или в PowerShell:   pip install -U yt-dlp
Для YouTube нужен Deno (проверка: deno --version).
Если нет:  winget install DenoLand.Deno


3. РЕЖИМЫ КАЧЕСТВА
------------------
- "Лучшее качество"        - как отдаёт сайт (может быть AV1/WebM).
- "MP4 (без AV1)"          - VP9/H.264 + AAC в MP4, как у оригинального Hitomi.
- 144p ... 4K              - потолок качества, MP4.
- "Только звук (mp3)"      - кнопка рядом с "Скачать".
Скачать заново в другом формате: правая кнопка на задаче -> "Скачать заново в формате".


4. ДУБЛЯЖ (несколько аудиодорожек)
----------------------------------
Настройки -> "Добавлять дубляж к оригиналу"  (или Параметры -> Основные).
"Языки дубляжа" - например ru или ru,de (пусто = все языки).
Оригинал всегда идёт первой дорожкой и помечен "по умолчанию".
Работает, когда у видео есть языковые дорожки (YouTube, ВК).
Проверка файла:
  ffprobe -hide_banner 'D:\hitomi_downloader_GUI\имя файла.mp4'
Нужны две строки Audio: (eng) default и (rus). В PotPlayer дорожки переключаются клавишей Tab.
ВАЖНО: в PowerShell путь с символом $ пишите в ОДИНАРНЫХ кавычках.


5. СУБТИТРЫ
-----------
Параметры -> Основные -> "Субтитры":
  Не скачивать / Отдельными файлами (.srt) / Вшить в видео.
"Языки субтитров" - по умолчанию ru,en (ru и rus считаются одним языком).
"Автоматические субтитры" - распознанные YouTube (включайте, если авторских нет).


6. YOUTUBE: "Sign in to confirm you're not a bot"
------------------------------------------------
Нужен вход в аккаунт через cookies. Надёжный способ (файл cookies.txt):
  1) Откройте в Opera GX ПРИВАТНОЕ окно и войдите в YouTube.
  2) В этой же вкладке откройте  https://www.youtube.com/robots.txt
  3) Расширением "Get cookies.txt LOCALLY" нажмите Export.
  4) Сразу закройте приватное окно и больше не заходите в этот сеанс.
  5) Сохраните файл, лучше в D:\yt_cookies.txt
  6) Программа: Параметры -> Сеть -> "Файл cookies" -> путь к файлу;
     "Cookies из браузера" - "Не использовать".
Проверка в PowerShell:
  yt-dlp --cookies "D:\yt_cookies.txt" -F "ссылка"
Если пишет "cookies are no longer valid" - файл устарел, экспорт повторить.
Лучше использовать запасной аккаунт Google. Не качайте слишком много подряд.
Файл cookies.txt - это ваш вход в аккаунт: никому его не отправляйте.

Вариант без файла: Параметры -> Сеть -> "Cookies из браузера" -> "Opera GX"
(Opera GX должна быть полностью закрыта, через диспетчер задач).


7. ВК
-----
"Video only available to followers" - видео только для подписчиков:
нужна подписка на сообщество и cookies ВК, это не ошибка программы.


8. ЧАСТЫЕ ОШИБКИ
----------------
"Requested format is not available" - обычно YouTube отдал только картинки:
   обновить yt-dlp, проверить Deno, настроить cookies (пункты 2 и 6).
"No video formats found" (некоторые сайты) - обновить yt-dlp:
   pip install -U --pre yt-dlp   и включить "Имитировать браузер".
Повторная вставка ссылки - программа переходит к уже существующей задаче.
Размер файла отличается от оригинального Hitomi - выбран другой кодек
   (VP9 обычно легче H.264 при том же качестве, это нормально).


9. ПОЛЕЗНОЕ
-----------
Скрепка слева от строки ссылки - вставляет ссылку из буфера и сразу качает.
Пауза: кнопка внизу (все задачи) или правая кнопка на задаче.
Наведите курсор на миниатюру - картинка увеличивается.
Шаблон имени файла: [artist] [title] [id], например [artist] title


10. ТОЛЬКО СУБТИТРЫ
-------------------
Стрелка рядом с синей кнопкой -> "Скачать только субтитры": скачиваются файлы .srt без видео.
Языки - Параметры -> Основные -> "Языки субтитров" (пусто - все). Имя файла такое же, как у
видео (при том же шаблоне имени), поэтому плеер подхватывает субтитры сам.
Если у видео нет субтитров на нужных языках, задача завершится ошибкой с пояснением.


11. ОБНОВЛЕНИЕ
--------------
Сайты не работают: Инструменты -> "Обновить yt-dlp и gallery-dl", потом перезапуск.
Новая версия программы: Инструменты -> "Обновить программу из архива" -> выберите zip.
Программа проверит файлы, сохранит старые в папку _backup_..., установит новые и перезапустится.
Настройки и список загрузок сохраняются. Постоянную ссылку на архив можно вписать в
Параметры -> Прочее -> "Адрес обновления" (только https и только из надёжного источника).
Первый раз (когда в папке ещё нет updater.py) файлы нужно заменить вручную.


12. ЗНАЧОК И СОВМЕСТИМОСТЬ
--------------------------
Значок-черепашка: файл turtle.ico лежит в папке программы. Ярлык на рабочем столе с этим значком:
Инструменты -> "Создать ярлык на рабочем столе".
Режим "Видео - совместимость, H.264 + AAC": для телевизоров, телефонов и старых плееров.
На YouTube H.264 доступен только до 1080p; если H.264 у видео нет, берётся лучший доступный поток.
